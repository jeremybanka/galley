# galley

Compose your Markdown.

Workspace for [galley.md](packages/galley.md), the compiler that turns MDX components and attributed source imports into plain Markdown.

The workspace also contains [an independent dprint MDX plugin](packages/dprint-plugin-mdx), which formats Markdown while preserving JSX and JavaScript.

See the [user guide](packages/galley.md/README.md) for installation, components, and editor tooling, and [repository commands](docs/commands.md) for contributor workflows.
